# Alliance Sourcing BD

A full-stack web platform developed for Alliance Sourcing BD, featuring a customer-facing web application, an admin dashboard, and a backend API.

The project is organized as a monorepo containing the frontend, admin panel, and backend services in a single repository.

---

## 🚀 Project Overview

Alliance Sourcing BD is a full-stack business web application designed to provide a modern platform for managing sourcing-related services and business operations.

The system consists of three major parts:

- Customer-facing Frontend
- Admin Dashboard
- Backend API
